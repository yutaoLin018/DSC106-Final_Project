About this project

The Greening Earth

This project explores how global vegetation has changed over time using MODIS NDVI satellite data. We convert vegetation intensity and long-term change into 3D map spikes so readers can compare broad global patterns and then zoom into selected regions.

Why this project?

Many people may assume that human activity has simply caused Earth to lose vegetation everywhere. Our project shows that the story is more complex: some regions are greening, some are declining, and the causes vary by place.

What the map shows

Green spikes represent areas where vegetation increased, while orange spikes represent areas where vegetation declined. Taller spikes indicate stronger vegetation intensity or larger change.

Dataset and method

The visualization uses MODIS NDVI data for selected years. The data is aggregated into map cells at different detail levels so the webpage can load smoothly while still preserving regional vegetation patterns. The change view compares vegetation values between 2000 and 2025.
